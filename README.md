# FinPulse – Personal Finance & Expense Analytics Dashboard

FinPulse is a personal finance analytics dashboard built with Python
and Streamlit. It helps users analyze bank statement data, categorize
transactions, track budgets, and understand spending patterns.

## 🚀 Features

- Upload monthly bank statement CSV files
- Automatic transaction categorization
- Income and expense analysis
- Category-wise spending insights
- Budget tracking and alerts
- Monthly spending trends
- Interactive Plotly visualizations
- Financial health insights

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- SQLite

## 📊 Dashboard

The application provides interactive dashboards for:

- Total Income
- Total Expenses
- Net Savings
- Savings Rate
- Category-wise Spending
- Monthly Trends
- Budget vs Actual Spending
